# Textos de referência para calibração

Coloque aqui textos humanos de referência, um por arquivo `.txt` ou `.md`, na pasta do nível:

- `iniciante/`: conteúdo de educação financeira para leigos (ex.: posts didáticos, newsletters para iniciantes)
- `intermediario/`: newsletters e análises para pessoa física que já investe
- `avancado/`: relatórios de research, cartas de gestores, comentários de economistas

O notebook `notebooks/calibracao_limiares.ipynb` usa esses textos, os documentos-fonte
(`data/processed/`, tratados como referência de "avançado") e as saídas do pipeline.
